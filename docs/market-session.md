# 거래 시간과 전일 대비

매일 한국 시간 09:00 이상, 21:00 미만에 신규 주문과 체결을 허용한다. 주말·공휴일 제외 규칙은 없다. Firestore request.time으로 운영 시간을 검사하므로 브라우저 시계로 우회할 수 없다. 장외 조회와 미체결 취소는 가능하며 미체결 주문은 다음 장까지 유지한다.

기업 화면의 전일 대비는 현재가에서 한국 시간 오늘 00:00 이전의 마지막 공개 체결가를 뺀 값이다. 전날 체결이 없으면 이전 체결가를 이어서 사용한다. 최초 거래일에는 초기 판매가를 기준으로 하되 ‘초기 기준가 대비’로 표시한다. 이전 체결 조회가 실패하면 전일 대비를 표시하지 않는다. 현재가는 최신 체결가이고, 첫 체결 전에는 초기 판매가이다.

등락률 = (현재가 - 전일 기준가) / 전일 기준가 × 100. 화면 가격은 실시간 시세 구독으로 갱신하며 종목을 다시 열거나 새로고침하면 전일 기준도 다시 조회한다.

# 회사 주주 명부와 자산 순위

기업경영의 주주 명부 탭은 담당 사장과 관리자만 볼 수 있습니다. 이름, 해당 종목 보유 수량, 발행 주식 수 기준 지분율, 회사의 미판매 주식을 표시합니다. 매도 대기 주식은 보유 수량에 포함하며, 비활성 계정이나 관리자도 실제 보유 주식이 있으면 포함합니다. 자산 순위 상위 100명과 관계없이 전체 계좌에서 집계합니다.

주주 명부는 거래 순간의 실시간 계좌 조회가 아니라 기존 자동 자산 집계와 함께 갱신되는 스냅샷입니다. 기존 15분 주기 GitHub Actions와 관리자 화면의 자동 집계가 사용되며 실행 지연이 있을 수 있습니다. 표시된 집계 시각을 기준으로 봅니다. 관리자의 자산 순위 갱신으로도 함께 다시 집계합니다.

companyShareholders/{companyId}에는 이름·익명 투자자 키·해당 종목 수량 및 회사별 합계만 저장합니다. UID, 이메일, 현금, 타 종목 보유 내역을 넣지 않습니다. 일반 학생·비담당 사장·미로그인 사용자의 조회와 사장의 쓰기는 차단하며, 기존 개인 계좌 접근 권한은 변경하지 않습니다.

개인 자산 순위는 총자산 순서를 유지하고, 보유 현금·주식 평가액·총자산을 각각 표시합니다. 현금에는 매수 주문 예약금을 포함하며 주식 평가액과 중복 가산하지 않습니다.

배포: Firestore 규칙과 사이트를 함께 반영하고, rankings-only 작업을 한 번 실행해 최초 명부를 생성합니다. 기존 자동 정산·순위 작업은 새 명부도 갱신합니다. 신규 서비스 계정이나 비밀키는 필요하지 않습니다.

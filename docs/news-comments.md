# 뉴스 상세와 댓글

- 시장 뉴스 목록과 왼쪽 시장 소식에는 헤드라인만 표시한다. 뉴스 링크 `#/news/{id}`를 열면 본문과 댓글을 조회한다. 새로고침·직접 링크·뒤로가기를 지원한다.
- 기존 기업 이벤트는 `#/event/{id}` 상세 페이지에서 기간과 내용을 표시하며 뉴스 댓글과 구분한다.
- 로그인한 활성 참가자만 뉴스를 읽고 댓글을 작성하거나 반응할 수 있다. 학교 이메일 인증과 기존 관리자 예외를 유지한다.
- 댓글은 1~1,000자, 사용자별·뉴스별 3초 간격이다. 작성자 이름은 등록된 프로필과 일치해야 하고 작성 시각은 Firestore 서버 시간을 사용한다. 본문은 HTML이 아닌 텍스트로 렌더링한다.
- 댓글은 최신 순으로 30개씩 읽으며 ‘이전 댓글 더 보기’로 추가 조회한다. 커서는 Firestore 타임스탬프의 나노초 정밀도를 유지한다.
- 좋아요·싫어요는 한 사용자당 하나만 선택한다. 선택한 버튼을 다시 누르면 취소하고 반대 버튼을 누르면 전환한다. 개인 반응과 집계 수를 같은 트랜잭션에서 갱신한다. 다른 사용자의 투표 문서는 조회할 수 없다.
- 동시 투표 때문에 보안 규칙이 최신 집계 상태와 충돌하면 실제 집계/본인 반응 변경을 확인한 경우에만 최대 5회 재시도한다. 권한 오류를 무조건 재시도하거나 무시하지 않는다.
- 관리자에게만 댓글 삭제 버튼이 보인다. 삭제 확인 후 댓글 본문과 작성자 표시 이름을 비우고 `관리자에 의해 삭제된 댓글입니다`로 표시한다. 삭제한 본문은 복구할 수 없다. 삭제 댓글에 추가 반응·내용 수정·복원은 금지한다. 기존 반응 문서는 본인에게만 읽히는 상태로 남지만 화면에는 표시하지 않는다.
- 삭제 표식에는 내부 작성자 UID와 기존 집계 등 최소 식별/상태 데이터가 남는다. 이는 계정 삭제나 하위 투표 문서의 영구 삭제 기능이 아니다.
- 무료 Spark 구조를 유지한다. 댓글 자동 폴링은 하지 않으며 페이지 진입/등록/새로 조회/더 보기 시만 조회한다.

데이터: `news/{newsId}/comments/{commentId}`, 하위 `votes/{uid}`, `news/{newsId}/commentLimits/{uid}`. 댓글 생성과 3초 제한 표식, 반응 변경과 카운터는 보안 규칙이 상호 확인한다. 타인의 작성자 사칭·카운터 직접 수정·투표만 쓰기·일반 회원의 삭제를 차단한다.

검증: 뉴스 직접 링크, 댓글 작성/재전송 중복 방지, 좋아요/싫어요 전환·취소·동시 투표, 사칭/권한 위조 차단, 관리자 삭제 후 본문 제거, 나노초 커서로 35개 댓글 중복 없는 페이지 조회. 실제 학생·실제 서비스 뉴스 대신 `demo-*` 로컬 에뮬레이터와 합성 계정으로 브라우저에서 확인했다.

# 청운증권HTS 화면 구성

공식 참고 자료: [영웅문4 주식종합차트 0601](https://download.kiwoom.com/hero4_help_new/0601.htm), [WTS 주식종합 5000](https://download.kiwoom.com/hero4_help_new/5000.htm). 화면번호, 상단 화면 전환, 차트·호가·주문 패널의 역할 분리를 참고했다. 타사 로고와 이미지 자산은 사용하지 않는다.

- 공통: 짙은 메뉴 바, 밝은 작업 영역, 상단 빠른 화면 탭. 키보드 포커스를 표시한다.
- 종합화면: 실제 등록 기업 수와 상장 수, 초기 기준가격이 있는 종목 목록, 계좌 이동, 시장 소식. 예정 동아리 수와 예상 참가자 수를 현재 집계처럼 표시하지 않는다.
- 종목화면: 최근 체결가, 주문 가능 자산, 체결 추이·호가·주문 패널, 하단 주문·체결 내역. 1200px 이상에서 3열, 중간 크기에서 2열, 780px 이하에서 세로 배치한다. 주문 표는 패널 내부에서 스크롤한다.
- 체결 추이는 기존 API가 반환하는 **로그인한 사용자의 최근 체결**만 표시한다. 전체 시장 차트나 OHLC 캔들로 표기하지 않는다. 0건은 빈 상태, 1건은 점 하나를 표시하고, 실제 기록 사이만 연결한다. 가격 데이터 생성·추가 쿼리·자동 주문은 없다.

검증: `pnpm test`, `pnpm build`. 로컬 Firestore 에뮬레이터의 합성 학생 계정으로 기업 A/B 전환, 호가 선택 시 가격 반영, 매수/매도 전환, 실제 체결 기록 표시와 빈 상태, 종합화면 이동을 확인한다. 실사용자 계좌나 주문을 디자인 검수에 사용하지 않는다.

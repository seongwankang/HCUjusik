# 2026-10-21 행사 초기화

`daily-economy.yml`의 `reset-2026-10-21` 모드는 회사, 경영·스파이, 주문·체결·차트, 뉴스·댓글, 이벤트, 순위를 초기화한다. 회원 및 관리자 권한은 유지하고 모든 회원의 현금은 100만 원, 주식은 0주로 설정한다. 회사 배정은 비운다.

작업은 `systemMaintenance/reset`으로 클라이언트 접근을 잠그고, 대상 문서와 하위 컬렉션 전체를 `resetBackups/fresh-start-2026-10-21/documents`에 백업한 뒤 삭제한다. 백업은 기본 거부 규칙으로 비공개이며 로그에는 인원수와 상태만 남긴다. 완료 영수증이 있으면 재실행은 아무것도 변경하지 않는다. 실패하면 잠금을 유지하고 같은 모드를 재실행한다. 서비스 계정·보안 규칙·회원·인증·운영 밸런스 설정은 삭제하지 않는다.

복구가 필요하면 정산과 거래를 잠근 상태에서 백업의 각 `path`에 `data`를 Admin SDK로 복원한다. 백업에는 개인 자산이 있으므로 내보내거나 공개 로그에 출력하지 않는다.

거래는 한국 시간 2026-10-21 08:00까지 UI와 Firestore 규칙에서 차단된다. 자동 정산도 이 시각까지 중지한다. 참가자 자산 순위 조회와 집계는 계속 제공하며, 실제 초기화 잠금 중에만 집계를 중지한다. 기존 브라우저 역사 캐시는 새 저장소 이름으로 분리한다.

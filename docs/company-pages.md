# 회사별 거래 페이지와 버전 갱신

기업 선택 시 팝업 대신 `#/company/test-a`, `#/company/test-b` 전용 화면을 엽니다. GitHub Pages에서 별도 서버 경로 설정 없이 직접 링크·새로고침·뒤로가기를 지원합니다. 로그인 전 직접 접속하면 로그인 안내를 표시하고, 로그인 후 원래 기업 페이지를 엽니다.

계좌 요약, 가격별 호가, 큰 지정가 입력 폼, 이 기업의 주문·미체결 및 체결 내역을 분리했습니다. 호가 가격을 누르면 지정가격에 입력되고, 매수/매도 탭으로 구분합니다. 관리자 전체 주문 취소는 관리자 계정에만 표시합니다. 종목당 4건 제한과 기존 거래 규칙은 그대로입니다.

예전 “지정가 매칭 서버 연결이 아직 완료되지 않았습니다” 문구는 비활성화된 서버 어댑터의 메시지입니다. 현재 일반/관리자 계정은 같은 Spark API를 사용합니다. 옛 브라우저 탭에 남은 이전 코드 혼용을 줄이기 위해 빌드 결과 HTML은 모든 JS 모듈을 묶은 `assets/app-[hash].js`와 내용 해시 CSS를 참조합니다. Firebase 공개 설정은 문서 기준 루트에서 cache:no-store로 요청합니다. version.json과 배포 버전을 비교해 새 버전 알림을 표시하며, 입력 중인 주문을 자동 새로고침으로 버리지는 않습니다. 기존에 열린 구버전 탭은 한 번 새로고침/재로그인이 필요합니다.

검증: 의존 JS 변경 시 엔트리 파일명 갱신과 HTML 참조, CSS 해시·버전 파일, 기업 주소 파싱 테스트. 일반 학생 API로 조회·미체결 접수·취소를 확인했습니다. 실제 Firestore emulator에 연결한 일반 학생 브라우저에서 호가 클릭 → 매수 체결, 매도 대기·취소, A/B 전환·뒤로가기를 확인했습니다. 실제 사용자 비밀번호·토큰·학생 데이터는 테스트나 저장소에 넣지 않습니다.

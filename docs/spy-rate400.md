# 산업스파이 탈취율 4%

1명당 대상 정산 일매출의 4%, 최대 2명(같은 대상이면 합산 8%). 고용비 100만원, 기간 제한 없음. 기존 대상 총 손실 상한(일매출 10%)과 보유 현금 한도는 유지한다. 모든 탈취는 일반 정산 매출 스냅샷으로 계산하며 서로 훔친 금액을 재탈취하지 않는다.

발각 보상은 4%로 계산한 예정 금액의 150%로 변경한다. 이미 지급된 정산·발각 보상·뉴스는 소급 수정하지 않는다.

현재 활동 중인 기존 스파이에도 적용한다. spyAutomation/two-agent-rate400-v3 영수증으로 기존 정책 전환과 구분하며, 고용 이력·회사 자금은 보존하고 종료된 스파이는 되살리지 않는다. 전환은 등록된 슬롯을 유지하면서 최대 2명 정책을 재확인한다. 규칙 게시 후 코드 배포 시 spies-policy-only 워크플로가 전환을 실행한다. 이 실행에는 정산·발각·자금이체가 포함되지 않는다.

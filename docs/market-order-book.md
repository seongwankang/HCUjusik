# 가격별 거래 현황과 10원 주문 단위

종목 화면 위의 같은 자리에서 ‘캔들차트 / 호가표’ 탭을 선택합니다. 처음에는 캔들차트를 보여주고, 호가표에서는 판매 대기 수량 / 가격 / 구매 대기 수량을 같은 가격 행에 맞춥니다. 오른쪽 주문창은 두 화면에서 공통으로 사용하며 전환해도 가격·수량·주문 방향이 유지됩니다. 작은 화면에서는 주문창이 아래에 놓입니다. 가격별 수량은 실제 주문장 집계이며 초기 발행 잔여 수량도 기존 주문장 계산에 포함됩니다. 현재가 주변의 빈 가격 행은 대기 수량 없이 표시합니다. 탭은 키보드 방향키와 Home/End로도 전환할 수 있습니다.

판매 대기 수량을 누르면 해당 가격의 매수 주문을, 구매 대기 수량을 누르면 해당 가격의 매도 주문을 준비합니다. 중앙 가격은 기존 주문 방향을 유지합니다. 클릭만으로 주문을 접수하지 않으며 수량을 입력하고 주문 버튼을 눌러야 합니다. 매수·매도 대기 주문은 기존 가격·시간 우선 규칙으로 체결됩니다.

신규 지정가 주문은 10~1,000,000원 사이의 10원 배수만 허용합니다. 입력창 `min/step`, ±10원 버튼, 클라이언트 API와 Firestore 신규 주문 규칙에서 검증합니다. 화면을 우회해 자금 예약·주문장·주문 문서를 함께 조작해도 1원 단위 신규 주문은 거절됩니다.

기존 주문·체결 이력과 회사 기준가는 임의로 수정하지 않습니다. 이전 단위의 호가가 남아 있다면 실제 가격·수량을 표시하되 그 가격을 새 주문으로 선택하는 버튼은 비활성화합니다. 이전 주문은 기존 규칙대로 취소·체결할 수 있습니다. 기존 미체결 4건 제한은 이 화면 변경에서 바꾸지 않습니다.

검증: 가격·수량 집계, 양쪽 주문 방향, 빈 행, 이전 단위 표시, 경계값·소수·1원 단위 차단 테스트와 전체 Firestore 거래·정산 회귀 테스트를 실행합니다. 운영 계좌로 시험 주문을 넣지 않습니다.

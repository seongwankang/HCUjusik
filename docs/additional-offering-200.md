# 2026-10-23 회사 소유 주식 추가 발행

현재 listed/paused 기업을 처음 실행할 때 고정하고 회사마다 200주씩, 주당 10,000원으로 추가 발행한다. companies.issuedShares 및 sparkBooks.issuedShares/treasuryShares를 각각 200 늘린다. 기존 미판매 수량을 대체하지 않는다. 초기 판매가격이 이미 10,000원인 발행 경로를 재사용한다.

회사/학생 현금, 투자자 보유 수량, 기존 주문과 우선순위 인덱스, 기존 체결가/기준가, 가격 제한은 수정하지 않는다. 판매 전에는 회사 현금을 지급하지 않으며 실제 체결 시 issuerCash가 증가하는 기존 정산 구조를 유지한다.

shareIssuances/additional-200-at-10000-2026-10-23 아래에 회사별 적용 영수증을 작성한다. 발행 수량 변경과 영수증은 같은 트랜잭션으로 커밋한다. 재시도 시 완료 회사는 건너뛰며 중간 체결로 줄어든 미판매 수량을 복원하지 않는다. 일반 거래와 충돌하면 Firestore 트랜잭션이 재시도한다.

모든 회사의 발행·미판매 수량과 1만 원이 당일 가격 범위 안인지 먼저 확인한다. 범위를 벗어나면 가격 제한을 임의 변경하지 않고 적용 전에 중단한다. 유지보수/정산 잠금 시 재시도하며 과거 배당 정산 스냅샷은 수정하지 않는다. 실행 후 기존 순위·주주 명부를 갱신한다. 운영 데이터는 커밋하지 않는다.

# 자산 순위 자동 갱신

기존 `daily-economy.yml`의 15분 간격 예약 작업에서 15분 이상 지난 자산 순위를 다시 집계한다. 매매 중단 기간에도 순위 집계는 계속되며, 실제 초기화 작업 중에는 집계하지 않는다. GitHub 무료 예약 실행은 지연될 수 있으므로 정확한 실시간 주기를 보장하지 않는다.

관리자로 로그인한 활성 브라우저도 집계 시각을 확인해 같은 15분 기준으로 자동 집계한다. 화면이 숨겨져 있거나 일반 참가자이면 실행하지 않는다. 한 브라우저에서 실행 중인 요청은 중복하지 않고, 실패하면 1분 후 재시도한다. 관리자 브라우저가 없어도 기존 예약 작업은 유지된다.

`/api/rankings-auto`는 기존 관리자 권한으로만 사용할 수 있으며, 매번 최신 집계 시각을 읽어 불필요한 전체 계좌 조회를 피한다. 일반 참가자는 공개된 순위·보유 현황과 본인 계좌만 읽는다. 집계는 순위와 공개 보유 현황만 게시하며 원본 계좌의 자금·주식·예약금을 변경하지 않는다. 기존 관리자 ‘자산 순위 갱신’은 즉시 재집계용으로 유지한다.

일반 ‘새로고침’은 최신 집계 결과와 현재 화면의 값을 다시 조회한다. 처리 중 버튼을 비활성화하고 완료 시각 또는 오류를 표시하며, 실패 시 기존 순위표를 보존한다.

# 참가자 초기자금 200만 원

신규 가입 및 미개설 거래계좌 기본 잔액은 client/initial-capital.js의 200만 원입니다. 새 가입 포트폴리오는 initialCapital: 2000000을 기록하며 Firestore 규칙에서 고정 금액과 초기 보유량을 검증합니다.

기존 student/president 계정(비활성 포함)은 initial-capital-2000000 모드로 현금 100만 원을 한 번 추가합니다. 관리자와 기업 계좌는 제외합니다. 거래 손익·주식·예약금·주문을 보존하고 버전을 증가시키며, 계좌가 없으면 200만 원으로 생성합니다. 신규 200만 원 가입자는 추가 지급에서 제외합니다.

capitalAdjustments/initial-capital-2000000-v1/users/{uid}에 변경 전 데이터를 보관하고 동일 트랜잭션에서 지급 영수증을 기록합니다. 학생은 읽고 쓸 수 없습니다. 중단·중복 실행 시 재지급하지 않으며, 전체 완료 후 자산순위를 다시 게시합니다. 로그에는 처리 건수만 출력합니다.

배포 순서: 새 규칙 게시 → main 정산 워크플로를 initial-capital-2000000 모드로 실행 → Pages 배포. 기존 탭은 새 버전으로 새로고침해야 합니다. 과거 reset-2026-10-21 작업은 이미 완료된 일회성 기록이므로 다시 실행하지 않습니다.

검증 중 기존 체결 규칙의 1000개 표현식 한도로 회사 운영 문서가 있는 두 계정 체결 테스트와 후속 테스트가 실패했습니다. 변경 전 main 규칙·100만 원 기본값으로도 동일한 실패를 재현했으며, 자금 변경에서 체결 권한이나 규칙 구조를 변경하지 않습니다.

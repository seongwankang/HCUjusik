# 관리자 학생 이메일 조회

학생 이메일은 공개 기업·뉴스 문서가 아닌 users/{uid} 프로필에 저장한다. 프로필은 본인과 관리자만 읽을 수 있고 목록 조회는 관리자만 가능하다. 관리자 목록과 학생 상세에 읽기 전용으로 표시하며 역할·활성 상태·담당 기업을 바꿔도 이메일은 유지한다.

신규 회원은 인증된 Firebase ID 토큰 이메일을 저장한다. 기존 프로필은 다음 로그인/세션 복원 시 /api/me에서 같은 검증된 본인 이메일만 채운다. 연락처 동기화 실패는 로그인 성공을 막지 않는다. 다른 사람의 이메일, 역할 또는 이름으로 덮어쓸 수 없도록 Firestore 규칙으로 검증한다. 관리자도 이 화면에서 이메일을 수정할 수 없다.

현재 Auth 계정 목록을 일괄 조회하는 권한을 새로 만들지 않는다. 기존 이메일 미저장 학생은 다음 로그인까지 '다음 로그인 시 확인'으로 표시한다. 순위표·기업·뉴스·다른 학생 계좌 조회에는 이메일을 추가하지 않는다.

기업 소개는 선택 입력으로, 빈 문자열이나 미입력은 빈 문자열로 저장한다. 2,000자 제한과 문자열 형식 검사는 유지한다.

# 내 자산과 거래 계좌

내 자산의 주 표시는 `/api/trading-portfolio`로 `sparkAccounts/{로그인 UID}`의 현금·보유 수량·예약 자산을 조회한다. 변경되지 않는 예전 `portfolios`를 매매 후 잔고인 것처럼 표시하거나 두 계좌를 합산하지 않는다. 기존 문서와 현금은 수정·삭제·이관하지 않는다.

- 보유 현금은 체결된 매수 금액이 차감되고 매도 금액이 들어온 현금이다. 미체결 매수 예약금은 이 현금 안에 포함된다.
- 주문 가능 현금은 보유 현금에서 예약금을 뺀다.
- 주식 평가액은 보유 수량 × 종목의 최근 체결가다. 체결가가 없으면 초기 기준가를 표시하고, 가격 자체가 없으면 평가 금액을 계산하지 않는다.
- 총 평가 자산은 보유 현금 + 주식 평가액이다. 예약금을 추가하거나 한 번 더 차감하지 않는다. 매도 예약 수량도 여전히 보유 주식이다.
- 자산 화면 진입과 새로고침에서 다시 조회한다. 다른 화면으로 이동하거나 로그아웃한 뒤 늦게 끝난 조회, 이전 새로고침 응답은 표시하지 않는다. 자산 조회가 매칭이나 주문장 갱신을 실행하지 않는다.

차트의 기본 SVG title 말풍선은 제거한다. pointerenter/pointermove에서 즉시 커스텀 정보 상자를 표시하며 날짜, 시가·고가·저가·종가, 거래량을 제공한다. 같은 봉에서는 정보 내용을 다시 생성하지 않고 위치만 갱신한다. 상자는 포인터를 가리지 않고 차트 내부로 위치를 조절한다. 포인터가 나가거나 Escape/포커스 해제 시 닫히고 키보드 봉 이동에도 표시된다.

상단 `0000 종합화면` 버튼은 제거한다. 기존 링크와 기본 진입 경로는 계속 지원한다. 보안 규칙이나 배포 설정을 바꿀 필요는 없다.

검증: 단위 테스트와 Firestore 에뮬레이터에서 실제 매수 체결 → 현금/주식 반영, 매수 예약 → 가용 현금 감소, 취소 → 예약 해제, 매도 예약 → 보유 수량 유지/가용 수량 감소를 확인한다. 다른 UID를 쿼리로 전달해도 본인의 계좌만 조회한다.
